# Windows Notch 🎵

A lightweight, transparent music widget for Windows that floats at the top of your screen — inspired by the Dynamic Island on iPhone. Displays your currently playing track with a live waveform visualizer.

![Demo](screenshots/demo.gif)

---

## Features

- 🎵 Displays current song title and artist in real time
- 📊 Live waveform visualizer that reacts to playback
- 🖥️ Works with Spotify, YouTube, and any Windows media player
- 🖱️ Drag to reposition anywhere on screen
- 🪟 Fully transparent, borderless — sits cleanly at the top of your screen

---

## Usage

1. Download and run `windowsnotch.exe`
2. Open Spotify or any media player and play something
3. The widget will appear at the top center of your screen
4. Right-click the widget to close
