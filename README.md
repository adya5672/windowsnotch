# windowsnotch
Windows Spotify Notch Widget

A Dynamic Island–style Spotify widget for Windows built using WPF and the Windows Media Session API.

The widget displays the currently playing track, album artwork, and playback controls in a compact floating interface.

## Features

- Spotify track detection
- Album artwork display
- Dynamic island expansion when songs change
- Animated waveform visualization
- Playback controls (Play, Pause, Next, Previous)
- Always-on-top floating widget

## Installation

1. Download the latest release
2. Extract the ZIP file
3. Run `windowsnotch.exe`

## Built With

- C#
- WPF (.NET 8)
- Windows Media Control API
